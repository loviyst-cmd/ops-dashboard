# 个人运营系统 v1.0

单人电商运营每日执行面板 - 时间轴规划 + 任务打卡 + 金币激励 + 日/周/月复盘。

## 功能

- **时间轴**：07:00-24:00 垂直时间轴，四列布局（时间/计划/实际执行/记录），列宽可拖拽
- **任务打卡**：三态循环（未开始 → 进行中 → 已完成），支持拖拽调整时间和时长
- **3件必做**：每日最重要的3件事，三态打卡（未开始 → 进行中 → 已完成）
- **进度条**：双段显示（绿色=已完成 + 蓝色=进行中），8小时工作目标
- **金币系统**：每30分钟工作 = 1金币，必做完成 +1金币，金币商店兑换奖励
- **复盘系统**：每日复盘 + 每周复盘（8项指标）+ 每月复盘，标签可自定义编辑
- **数据持久化**：LocalStorage 本地存储，无需后端

## 使用

直接用浏览器打开 `index.html` 即可使用，数据保存在浏览器本地。

## 技术栈

纯 HTML/CSS/JS 单文件，零依赖，零构建步骤。
